---
name: Student assessment purpose
description: Why Adhyayaan collects learner assessments and how students enter that process.
---
The user requested a psychometric test to inform adaptive learning, AI-enabled custom teaching and career counselling, with a detailed analytical report covering positives, negatives and suggestions saved in the student's profile.

**Why:** The user wants assessment profiling to improve teaching and career guidance, not merely produce a test score.

**How to apply:** Connect reports to the learning journey and career exploration rather than presenting an isolated questionnaire.

The assessment is mandatory after new signup. For existing signed-in users, add an option on the homepage after login to complete it.

**Why:** These are the user's explicit onboarding requirements; existing users were not asked to be locked out.

**How to apply:** Preserve the distinction between new-account onboarding and the existing-user homepage entry point.

The user wants the next question to adapt to previous answers, and a retake no more than once a week. Use a rolling seven-day wait from the last submission, not a calendar-week reset.

**Why:** The user wants assessment paths to reflect student responses rather than give everyone the same test, and wants retakes spaced apart.

**How to apply:** Keep the server as the source of truth for question paths and retake eligibility. Preserve submitted reports and saved drafts when introducing a new question version. Explain that scores on different paths are not directly comparable.

The user supplied a 500-item student assessment draft as a source for clearer test questions and says its current wording and some questions are unclear or improper.

**Why:** They want the test to use this material after its questions are improved, rather than copying unclear items unchanged.

**How to apply:** Select and rewrite items into simple, fair questions. Do not treat the draft as a validated IQ or personality test; its situational-choice section has no validated scoring key.
